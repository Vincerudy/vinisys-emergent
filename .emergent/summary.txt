<product_requirements>
The primary goal was to launch and stabilize the Vinisys payroll application, starting with a functional login. This evolved into a comprehensive refactoring of the Dépenses module into two distinct, feature-rich modules: Achats/Dépenses (Company Expenses) and Notes de frais (Employee Expense Reports).

For Notes de frais, the key requirements were:
1.  **Structure:** A Note de frais should function as an envelope containing multiple individual Frais.
2.  **Creation/Editing of Frais:** A dedicated interface (sidebar) for creating/modifying individual expenses, featuring:
    *   Manual entry for details like vendor, date, amount.
    *   OCR simulation for receipt processing (later changed to real data).
    *   Automatic calculation of HT/TVA.
    *   Inclusion of a Type de frais field (e.g., meals, fuel, mileage) from a dropdown.
3.  **Note Details:** A page to view a specific Note de frais and list all its contained Frais, with a dynamic total amount.
4.  **Submission Workflow:** A Soumettre (Submit) button on the note detail page that, when clicked, changes the note's status to Soumise, hides action buttons (upload, new expense, submit), and displays a confirmation modal.
5.  **Expense Note List:** A list page displaying all expense notes in a table format (initially cards, then changed to table), with filtering and navigation to note details.
6.  **Editing Existing Notes/Frais:** Ability to open a note/frais in an edit mode with pre-filled data.
7.  **Configuration:** A dedicated Paramétrage page for Notes de frais to manage and configure Type de frais (add, activate/deactivate).
8.  **Validation:** Submitted notes should appear on a Validation notes page, allowing batch or individual validation, changing their status to Validé.
</product_requirements>
